# Upgrade de grafana

Nous allons effectuer la mise à niveau de notre grafana installé à l'aide des images docker.

Nous souhaitons effectuer la mise à jour de la version **10.0.1** vers la version **12.1.1**.<br>
**NB:** Il faut noter que grafana stoque ces configuration dans un fichier sqlite notemment le fichier grafana.db qui se trouve dans le repertoir **/var/lib/grafana**.<br>
l'idée est juste de changer l'image de base de conserver le fichier de base de donnée sqlite **grafana.db**.<br>

Pour le faire nous allons suivre les etapes suivantes:<br>

1- Recuperation de l'image sur le docker hub

```
podman pull grafana/grafana:12.1.1
```

2- Arret de l'image 10.0.1 actuellement en en cours d'execution: <br>

```
podman stop my-grafana-container 
```

3- suppression de l'image 10.0.1 actuellement en en cours d'execution: <br>
```
podman rm my-grafana-container
```
4- Demarrage du container avec la nouvelle image.
```
podman run -d --name=my-grafana-container --restart=always -v $HOME/grafana-storage:/var/lib/grafana grafana/grafana:12.1.1
```

NB: le repertoire $HOME/grafana-storage contient le fchier sqlite que nous souhaitons monter dans la nouvelle image <br>
la section **2.Installation.md** vous apprendra surement plus sur l'origine du repertoire **$HOME/grafana-storage**
